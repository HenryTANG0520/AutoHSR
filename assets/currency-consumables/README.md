# 货币战争消耗品来源与校准

员工投影仪、完美投影仪、两种拆装扳手、冶金炉及好运令牌的初始参考图沿用[March7thAssistant固定装备来源](../upstream/March7thAssistant/equipment/sources.json)，没有改写其18幅PNG。原生金色扳手变体从既有4.6画面裁出75×70区域，排除次数、UID和整图；原图、清单、坐标、变换与输出哈希见[sources.json](sources.json)。游戏美术归HoYoverse及相应权利人，来源记录不授予额外许可。

[库存识别](../../autohsr/currency_wars_consumables.py)分别扫描十二格物品及顶部两个工具控制。图标仍要求0.92匹配和0.025候选差距；数量独立解析，不把一次模板命中当成持有一件。顶部必须看到0～99有限数字或独立的横向双孔无限符号；数字8、两个0和OCR冲突不能代替无限次。局部数字使用原图与二值图双读，每次至少0.90且内容相同；全图已有的矛盾或低可信读数不被覆盖。

下方单件物品只有在数量区没有任何OCR读数、没有可见数字形状且没有无限符号时，才记录`single_cell=1`。有徽标而读不清仍为未知；顶部按钮不使用这个例外。物品及徽标合并签名，未知格保持在库存账中。匹配缓存仅复用完全相同的区域像素，当前数量与文本仍重新解析。

本地既有174份清单中，22份备战页可见这些工具，均在顶部；三份校准回放经实际局部OCR识别为冶金炉1／2／2、金色扳手无限次。原图和清单哈希不变。下方工具、投影仪使用、令牌选择页及实际效果目前只有合成机制检查，**没有独立实机留出或整局验收**；未训练或更新模型。清单另记既有拆装、同品质重铸、员工投影仪及令牌教程的来源，不发布其整图。

[执行协议](../../autohsr/currency_wars_standard_consumables.py)仅供本局“阿格莱雅／希儿”策略：一次正式Context拖动后核对实际库存，再重新读取全部角色。员工投影仪核对一个一星副本的新增或合并；完美投影仪核对实际新增／升星，不猜定固定复制星级。扳手要求全部已知装备返仓、目标卸装；冶金炉目前只将仓库一件已识别简易装备重铸为另一件同品质装备；令牌分别记录使用、四选一与所选装备到账。每节点最多十二次，默认策略不使用这些命名核心工具。

对角色全部穿戴装备重铸、未知装备、未知复制规则、其他布局和全部特殊效果仍未支持。只核对库存变化不能结束使用；旧面板、暂停、跨运行、账号变化、写账失败或反馈不明，均保留原意图与证据，不重复消耗。实现与本轮验证见[开发记录](../../docs/currency-wars-development.md)。
