本项目继续使用AutoHSR原生投资选择、Context和逐角色查看，不迁入上游按标题或图鉴标记默认选择、缓存增加特殊角色计数的输入／状态实现。原末节点完整阵容来源、确认后完整重采、实际新增／升星、合并装备守恒和逐角色关闭回执属于AutoHSR扩展。

原生效果语法来自既有4.6的150号投资选项匿名字段记录。其样本与PNG哈希见[sources.json](sources.json)，只保留来源标识与校准范围，本目录没有复制原图、好友昵称、UID或账号数据。既有字段只证明“借力球比例提高0.15%、获得黑塔和缇宝”的完整文本，不证明实际领取；其他数量与星级／费用变化、全部输入和回执链均为合成检查，没有训练模型或独立真实留出。

游戏文本与画面仍归HoYoverse等各自权利人所有，源码许可不额外授予游戏美术权利。本轮没有新增游戏采集或分发图像；实际支持与未验收边界见[功能说明](../../docs/currency-wars-investment-units.md)。
