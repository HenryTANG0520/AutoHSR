# 货币战争自动战斗控件：只读观察

本目录保存2026年10月30日从已有本地货币战争证据裁出的最小右上控制组，以及两幅控件图形。没有新启动游戏、采集游戏画面、训练模型或实机切换自动战斗。游戏画面版权归HoYoverse及相应权利人；这些技术回归裁片不授予额外游戏美术许可。

`sources.json`仅保留匿名样本ID、日期时间、已核实版本或`unverified`、原始尺寸、裁剪范围和哈希；不包含UID、角色资料、账号指纹、原始文件名或安装路径。公开PNG只含倍速／自动／暂停控制的区域，没有原始整图。素材仅裁切，未改色或补画；测试中的缩放、遮挡、灰度等变体另标为合成检查。

`cw_on_01`是2026年10月26日标准开发局的既有4.6.0画面。自动图形与已有真实DU开启图形匹配，并且同时具有可核实的暂停控件及相邻关系；它用于本次局部校准。另两张同局邻近帧的大招遮挡了暂停，不作为独立留出或完整控制组正例。历史白灰斜杠控件分别与既有真实饰品禁用图形交叉核对，达到两个独立图形门槛才返回`disabled`；较弱匹配保持`unknown`。旧10月18日图片未从对应报告取得经核实的客户端版本，因此仍标`unverified`。

[只读检测器](../../autohsr/currency_wars_auto.py)的`read_auto(scene, confidence=.65)`返回不可变的`on/disabled/unknown`、分数与匿名诊断，`to_dict()`可转JSON。它先核实CW战斗页面，再核实当前右上图形、独立真实状态参考及暂停组上下文；金色只在已匹配图形内部参与判断。没有点击点位、热键、状态修改或开启动作。调用方仍须独立核实本次出战、节点、账号、客户端、新鲜画面和输入代次；本地历史裁片不授权现场输入。

**当前没有真实关闭状态或关闭→开启的操作前后证据。** 既有DU白色关闭检查由真实开启图灰度化而来，不能记作真实关闭样本。本模块不提供`off`，也不把白色、斜杠、缺少字母C、缺少控制或动画转换当作关闭，更不生成可点击位置。`on`只表示当前可见开启状态，不证明本程序发送过开启动作。完整自动开启仍未支持，实际CW切换和整局仍待验收。

真实控制局部校准、历史回放、同局邻近帧和合成Scene／CV检查分开记录。没有新的独立真实留出或实机验收；不得将本目录写为自动开关完整支持或新增通关。历史独立标准整局仍0/10，已终止的旧十场目标未恢复。
