## 使用方式

GUI 左侧“差分宇宙”与“货币战争”并列，每次可选 1–10 局，默认 3 局。命令行入口为：

```powershell
.\.venv\Scripts\python.exe -m autohsr --differential-universe --du-mode periodic --du-team "哈哈哈哈" --du-runs 1
```

默认周期演算，周期难度沿用备战页已选值。每次新开局都打开“下载角色 → 预设编队”，按名称选择“哈哈哈哈”（火花、爻光、银狼LV.999、真珠），核实同一行“已启用”和四人完整后启动。未找到名称、编队不完整或模式不一致均停止；不会按角色列表逐个拼队。GUI 可填写预设名称，CLI `--du-team` 临时指定。常规模式代码保留，当前暂不执行常规实机验证。

“保存通关存档”和“领取红点奖励”均默认关闭。CLI 可分别用 `--du-save`、`--du-rewards` 临时开启，不会自动写回配置。独立通关验证不保存后续存档。

保存开启时，仅使用空槽，不覆盖已有档。首次编号 AutoHSR-1；后续取当前列表最大编号加一，例如 AutoHSR - 2。槽位已满时记录跳过。10月23日只读核实 AutoHSR-1 存在，保存日期为10月21日，队伍为指定四人；后续验证关闭存档。程序自动键盘命名仍需单独实机验证。

红点领奖开启时，从差分宇宙主页定位拟合等级、月下奇谭、稳态数组等带红点入口，逐页处理并返回复核。月下奇谭会使用已获得的月下卡带，逐次核实 100 卡带价格和余额；不兑换卡带。奖励必须以“获得物品”弹层核实，未来奖励的详情弹窗不算领取成功。黄色“新”标记不等于可领取红点。

可能性画廊按分类红点进入，再打开左下角带红点的“奖励进度”，仅点击已达成档的“领取”，核实获得物品并逐层返回。边缘红点指向画面外分类时，按相反方向按住左键拖动画廊，并核实分类位置变化；左右两方向均已实机验证，不点击画面内装饰箭头。祝福、奇物、惊世奇迹、方程、事件五类奖励弹窗已逐类检查，共用“累计解锁数量达到”行及领取、进行中、勾号状态识别；加权奇物页没有独立领奖按钮。中断在分类或奖励弹窗时可接续，未知红点保留证据并停止。

意外中断后，可用 `--resume-active-du` 接续当前常规演算，接续局不计入新请求局数。用户已选择的周期演算可用 `--resume-active-du --du-periodic-rank 5 --du-runs 1` 接续；周期局只完成当前局，不误开常规模式。

## 识别与行动

本地粉色门模型 `assets/models/du_target.onnx` 以一个 Target 类识别睡眼门、苏醒门和门背面，运行于 ONNX Runtime CPU。模型只提供目标方向，不能授权跳过战斗或开睡眼门。许可证、数据划分、SHA-256 和评估限制见 `assets/models/`；训练工具依赖与运行环境分离。

远处门因动画导致置信度下降时，仅在门脸特征落入同一个低置信度检测框内才补充方向；不全局降低阈值。前往门的移动观察器只跟踪门，不混入敌人目标。

门脸被状态面板遮住或从侧面观察时，可在已检出的门框内联合复核一只完整白色眼环、暗色瞳孔、粉色门板和金色长竖框，补充确认苏醒状态。缺少模型框或门板特征不能采用单眼判断；睡眼门与蓝色旗帜继续作为反例。对正已确认苏醒的门后若检测框短暂消失，最多沿刚核实的方向接近两段 600 毫秒，并持续检查 HUD、障碍与交互提示。

门背面尺寸上限随实际搜索区域计算，近距离顶部被裁切的门板也可触发有限绕行。候选只有铸造或商店时允许选站；铸造、商店、财富和冒险现场先处理可交互卡片，确认门苏醒后再前往出口。选站授权不允许购买或铸造。

卡片区域一旦确认门苏醒，出口目标优先于卡片或设备候选，避免远处广告牌的误检重新牵引角色。目标仍可见时采用当前门的位置，只有目标确实短暂消失才使用有限直行补偿。近距离确认门背面时最多绕侧一次重新观察门脸；背面本身不证明可通行，也不授权交互。

一处区域可以包含两张或三张交互卡片。每次事件结束后重新识别现场，门仍睡着时继续处理剩余卡片，不用已交互次数推断完成；只有确认苏醒门或当前随意门交互提示才进入出口流程。多个卡片候选优先按识别置信度选取，再比较方向，避免居中的广告牌盖过侧边真实卡片。导航记录包含门状态、候选数量和检测框，供实机复核。

2026-10-23 增量模型加入粉色装饰画笔、墙面广告和造物调试台反例，以及电视购物频道卡片正反面；补充蓝色维护市容卡片复习，保持既有阈值。原有验证/测试分组未改动，新房间帧只作训练和同场景校准，不能用于宣称独立通关成功。

场景卡牌使用独立的 `assets/models/du_cards.onnx`，类别为 Card，CPU 单帧约 21 毫秒。当前训练集含26张原生训练图与776张仅用于训练的变体，涵盖紫色、青色、金色、蓝色及窄侧面卡片，并保留街景广告、画笔、旗帜和设备反例。阈值保持0.80，原有4张验证图和8张测试图不变，CPU评估分别为 TP4/FP0/FN0、TP3/FP0/FN0。样本较少，这不能代替独立通关验证。运行时不以颜色边框规则兜底。

区域类型优先读取左上角位面进度栏，避免奖励站的“商店街一番战”卡片标题被当成商店站。新进入卡片站时先沿初始朝向有限接近；可见的已校准卡片标题也能在图像漏检时补充方向，但不授权 F。当前文字补充覆盖“商店街一番战”“维护市容（区域）”，无卡片方向时也可向“造物调试台”标题接近。交互仍需实时提示；商店街事件已实机选择无负面奇物的 300 宇宙碎片及相关奇物奖励。

铸造等七类卡片站在没有可识别卡片时保留首次进场的有界直行接近；已有卡片方向时直接对准，并在出现 F 图标时立即停止持键。“维护市容（区域）”与“造物调试台”的名称若出现在右侧交互行，仍需同时匹配真实 F 图标才允许交互。造物调试台的已识别加权奇物菜单可关闭并记住本次已访问，继续寻找卡片，避免反复打开可选设备。维护市容已由接续实机完成事件、保守退出并经苏醒门进入下一站；这不计作独立通关。

奖励区域的“战利品”“丰厚战利品”宝箱同样由名称、右侧交互行和真实 F 图标共同授权领取。F 图标已经出现而名称未知时原地复查两次后停止，避免在宝箱前重复微步或误触发绕侧脱困。

一张事件卡处理完而门仍睡眠时，继续寻找其余卡片。“幻月之下（烬土）”的侧面极窄，模型可能漏检；现场中央带中文区域括注的浮空标题可补充粗略方向，须有左上角位面进度栏，并排除 HUD 区域。标题本身不授权 F。该侧面卡片已接续实机完成 150 宇宙碎片选项，并通过苏醒门进入下一站。

敌人方向由 `assets/models/du_enemies.onnx` 补充，覆盖金人司阍、资深员工·组长、正阳狮鹫、金血忆灵·裁定、乐变化天人、承露天人及波涛夫人七个已观察外形。主模型没有可用方向时，上一版 `du_enemies_fallback.onnx` 补充遮挡目标。组合路径在八张邻近校准正样本中可检出目标，十二张背景测试图无检测；七张测试敌人图中六张完整框匹配，乐变化天人的强进场特效图仍漏检。主模型 CPU 单帧约 22 毫秒，含补充模型的校准中位数约 38 毫秒。这不能证明通用精度或独立通关可靠。完全落在角色自身区域内的小目标框不作为敌人方向。攻击圆环结合红色圆弧、内部光晕和亮核，兼容脉动变暗及左侧近身圆环；敌人模型本身不授权攻击。

波涛夫人圆环被外侧亮眼眶包围时，补充使用红色超出其他通道的强度提取圆弧；保留原有几何及颜色限制，并排除高亮白字图案。三张原本漏检的实机截图回放通过，接续测试已自动重新定位并接战。

深寒徘徊者出现的暗色空心攻击圆环，使用相同红色特征的完整标记模板补充识别，匹配外圈、刻度与内圈，不依赖内部铺满亮光。模板阈值仅经本地邻近截图校准，圆环仍与顶部敌人等级信息条共同确认提前停止接近；接续实机已切换到弱点匹配的火花并普攻接战。

新位面先保持正前方。刚确认进入新战斗站时，先重新观察以等待进场动画消退，再沿初始方向有限接近一次；敌人信息条可能在动画期间缺失，不作为转镜头的触发条件。断线续跑不采用这个朝向假设，优先用粉色门恢复方向。其余目标缺失时只原地转镜头搜索。完成接近或真实攻击圆环出现后停止转镜头，并按可读弱点选择角色接战。清场后只在实时随意门交互提示出现时进入下一站。异常和奖励区域逐张处理卡牌，直到出口苏醒；睡眼门不能作为区域完成的证据。

新站正前方已有门时也保留这段初始接近，不因单帧门检测下降立即转向。相机刚对正已识别敌人而角色将其遮挡时，最多沿已核实方向接近两段 600 毫秒，实时圆环与卡死监测持续生效；不依赖敌人信息条一直可见。

首站同样保留新开局的初始朝向，面具与教学弹层不会清除这一状态。战斗进场与对正敌人后的单次直行上限从 4 秒缩短到 3 秒，出现攻击圆环时仍提前停步并左键接战；接近已完成区域的出口和卡片的时长另行处理。备战页等待头像和启动按钮完成淡入；说明中的“战斗胜利后”不能作为战斗结算识别依据。

从指南进入时，旷宇纷争页签匹配行星图标的稳定部分，排除通知红点和被内容面板遮住的底边，避免领完红点奖励后入口模板失效。仍需核实指南标题与页签区域。

“信标已部署”说明页在底部关闭提示将“白”误读为“日”时，仍需核实标题和提示位置才接受。关闭后重新观察当前页面，同一种弹层最多三次实时提示授权的点击；进入标题不同的新奖励弹层视为进展，重新处理。避免动画期间一次点击未生效后停在未知页、误将连续奖励当成关闭失败，或无界重试。

连续获得祝福与展开多个方程时，以奖励标题及方程名称区分不同弹层；标题同为“方程展开”而名称不同也算进展。单个内容不变的弹层仍保留三次关闭上限。

战斗结束后的已清场状态跨奖励页面保留，苏醒门或实时随意门提示也可确认清场，下一站与新开局才重置。苏醒门已核实后，不再用偶尔误识别的街景装饰寻找敌人。门交互后先复查：若仍在原场景，保留清场状态并有限重定位，最多两次实时提示授权的 F，不盲目连按。该恢复流程仍在实机复验。

新战斗站保持开场朝向，有限直行至圆环提示或三秒上限后直接左键接战，不再要求重新找回圆环。若已观测到圆环，切换角色或特效将其遮住也直接原地攻击；两次未接战则停止。卡死、提前丢失现场 HUD 等中断不作为已完成接近。

移动中命中攻击圆环时，保存当时的遮盖账号标识截图及圆环坐标。接近后的圆环丢失不再触发左右镜头搜索。需要重新定位时优先将粉门对正，避免为了追踪侧边怪物改变已正确的前进方向。

新战斗站首次接近不因模型只检出侧边怪物而改变初始方向。按用户确认的规则，完成直行接近或刚观测到圆环后，已识别战斗位面现场即可发送有限次数的左键攻击；实际左键不移动鼠标指针。7/13 卡住画面经手动一次左键已直接清怪并进入祝福选择；该次接手不计独立成功。

圆环的颜色与亮核也可能出现在随行物件的表情中。进入范围状态前必须同时核实顶部敌人等级信息条；连续移动观察器仅在出现圆环候选时补读这块小区域，避免物件表情取消新站正前方接近。

远处橙色数字气球即使同时出现敌人信息条，也不能作为攻击范围。检测额外排除圆心被大块白字填满的候选；误报截图不再取消新站正前方接近，已有近身、空心和强特效真实圆环回放仍通过。

同色的跟随物橙色帽子、粉色道具和门旁光带也可能产生圆形候选。强红弧额外排除偏黄橙色，并以攻击 UI 外圈的环形模板复核形状，忽略内部随动画变化的填充；现有真实圆环与新增反例回放通过，仍需顶部敌人信息条共同确认范围提示。

真实圆环可能靠近屏幕右侧队伍栏；搜索范围扩展至屏宽的 96.5%，继续执行颜色、圆环形状及敌人信息条检查，避免已停止接近后遗漏仍然可见的右侧目标。

移动线程持续持键，观察线程检查目标、交互提示和背景位移。接近目标后减速，2 秒背景不动触发有限次后退、绕侧；红色三角阻挡方向不继续前进。暂停、焦点丢失、异常或退出均释放持键。F9 暂停/继续，F10 紧急停止。

区域搜索的 90 秒上限不抢在已核实的当前 F 提示之前退出。新观察帧已出现随意门或受支持交互时先发送交互，并保留三次实时提示操作上限；没有有效提示时仍在超时后停止任何新移动。

单场景定位上限 90 秒，单局总上限 60 分钟，给周期难度 V 的多波战斗留出时间；场景卡死监测与战斗超时仍各自生效。

跨天列车补给优先于战斗或场景识别；复用日常流程的正数剩余天数、免费入口及中央 90 星琼校验，分两阶段领取与关闭后继续当前演算。每个阶段只发送一次，购买入口或未知数量停止。最终首领后的跨天弹窗已实机验证。
