本次实机页面显示：

- 当前赛季为“乐园漫记”；“常规演算”和“周期演算”是两个入口。周期演算有独立的计时、额外拟合值进度和周首领配置。
- 常规演算配置页显示当前难度、队伍和“进入星阶模式”。自动流程只在常规演算中选择最低难度 I，并保留当前队伍。

## 操作与报告

GUI 左侧“差分宇宙”与“货币战争”并列。每次可选 1–3 局，默认 3 局；命令行等价入口为 `--differential-universe --du-runs 3`。该操作不创建或修改每日刷本预算，也不会执行每日任务。

意外中断后，可用 `--differential-universe --resume-active-du --du-runs 3` 接续常规演算；该选项只接受已识别的运行中战斗、位面路线、队伍或奖励选择页面，不会在主页启动新档。普通接续局仍不计入新请求的局数。若已从用户选好的周期演算页启动，并要把当前周期局作为本次请求的一局，须明确提供所选难度，例如 `--differential-universe --resume-active-du --du-periodic-rank 5 --du-runs 1`；周期接续只完成当前局并计数，不会因局数仍未满足而误开常规模式。首次进入时的面具和方程选择会识别可见的确认按钮，教程的说明卡会按页面提示逐页关闭。差分宇宙操作后的空白加载帧会等待并重新识别，等待期间不会发送输入。

自动化仅在当前赛季页面、区域类型和按钮被明确识别后输入。路线抽取有战斗区域时优先选择战斗，再选奖励或休整等可识别区域；“选择下一站”页面优先选择战斗卡，只有没有战斗卡时才考虑异常卡，不选铸造卡。祝福、方程、奇物、面具和奇迹奖励先选一个可识别的免费候选，再确认一次；确认后页面未变化便停止，不重复点击。进入回合制战斗后，自动战斗开启状态须通过现有游戏图标校准确认。

第一位面战斗区域如果暂时没有可见敌人，只执行有次数与时长上限的镜头搜索和探索移动；攻击需要锁定标记模板，或“位面战斗 HUD + 敌人名称 OCR + 可见敌人图像模板”同时确认。周期演算 OCR 偶尔漏掉“第一位面”中的“一”，只在同帧仍有 1/13 进度计数、位面战斗标签和 Lv1/20 HUD 时兼容识别；单独的残缺标签不授权输入。可见敌人模板只说明敌人在画面里，首次点击前会先校正横向位置，再以两次 600ms 正向移动逐步接近，每步重新识别；若攻击动作后仍停留在场景战斗页，则必须重新接近后才允许第二次尝试。当前有敌方名称时优先战斗；即使目标模板暂时未匹配，也不会走随意门跳过战斗。敌人图像模板包含当前玩偶敌人的警戒态、静止态、先前视角和本次靠近视角，以及一名已观察到的惊梦剧团敌人，阈值 0.70，并仍受敌名 OCR、第一位面 HUD 和场景区域三项约束。警戒动画会显著改变单帧相关度；远处点中玩偶只转向、没有触发回合制战斗的情况已记录为未完成，之后需要对进入视野的敌人重新识别，不能把镜头变化当作接战成功。新敌人外观需要追加样本并实机核对。红色三角等场景图案不能授权点击。敌人被清除后，若战斗场景出现明确的随意门交互提示，才按提示进入下一战斗区域。异常区域不是战斗场景，完成条件是与场景中的卡牌交互；先短距离接近，只有 OCR 识别到明确的卡牌交互提示时才按 F，并确认交互后区域发生变化。随意门只是出口，不能代替异常区域卡牌交互。没有明确提示或交互后页面不变时停止并留证。

流程保留现有队伍，不使用燃料、星琼或开拓力，不购买、合成、重铸或消耗差分宇宙碎片。商店和合成页面只尝试安全离开；补充资源提示、未识别页面或未确认胜利结算会停止并留证，不会重放旧动作。周期演算读取用户已选队伍及页面显示难度；它与常规演算最低难度 I 的完成记录分开统计。

每次运行的 `report.json` 记录请求局数、已返回局数、页面 OCR、截图路径和动作状态。`evidence_manifest.json` 记录报告、日志、截图和 OCR 文件的 SHA-256；同目录 `evidence_manifest.sha256` 校验清单文件本身。
