# AutoHSR 界面与交互指南

2026-11-05 · v1。以用户提供的P1「每日实训」为基准。P2「游戏连接」使用同一个指南外壳，表单保留名称、当前值和相关操作。新页面按本指南选用组件与布局。

## 页面层级

| 层级 | 放什么 | AutoHSR示例 |
| --- | --- | --- |
| 窗口 | 场景背景、左上标题、指南书框、底栏 | [共享窗口与底栏](../autohsr/desktop.py) |
| 一级页签 | 用户常去的功能区，固定图标与顺序，悬停显示名称 | 每日实训 → 生存索引 → 旷宇纷争 → 记录 → 设置。选中页签亮底深色图标，[指南组件](../autohsr/game_widgets.py) |
| 二级导航 | 当前页内的分类或视图，用文字标明用途 | 设置的游戏连接、每日任务、体力计划、周常计划等。二级分类留在浅色书页内，[设置组件](../autohsr/desktop_settings.py) |
| 内容 | 当前分类的对象、状态和动作 | 每日用卡片，副本用分组列表，设置用表单行，模式入口可用海报，记录可用可滚动文本 |
| 弹窗 | 完成一个有明确开始和结束的操作 | 选副本、应用支援偏好、确认退出。沿用纸面标题与底栏，[弹窗组件](../autohsr/desktop_dialogs.py) |

一级切页保留指南位置，二级切换只换内容。首页卡片或周常入口可直达对应设置，并聚焦相关控件。从快捷入口返回原页面及焦点。Esc优先关闭展开的选项或弹窗，再退出当前子页面。指南右上关闭对应退出应用，子页面用明确的「返回」。

书框右上「工具」直达「设置 → 工具」，仍使用同一工具页与运行控制。返回恢复原页面和工具入口焦点。一级图标用左右键移动焦点，按 Enter 打开。进入工具后，用左右键切换分类，Tab 进入选中工具的表单。

## 视觉与操作

| 共同规则 | 可按任务调整 |
| --- | --- |
| 沿用现有字体、深色页签条、浅色纸面、金色焦点及共享控件主题 | 海报可用玩法原有配色。记录、表单和列表按信息密度选布局，见[主题](../autohsr/theme.py) |
| 每个视图突出一个执行动作。通用主动作在底栏右侧，保存等辅助动作在左侧 | 已有玩法海报可在画面右下放置唯一主动作。编辑、结果或记录打开后由底栏接管同一操作 |
| 控件贴近作用对象。项目名、当前值、资源和具体动作用位置区分 | 列表行可提供更换、加入或编辑。表单用行，必要时用横向值区容纳路径或多个短动作 |
| 小窗口先保留可读字号、可点击范围、导航和底栏 | 长内容在自己的区域滚动，键盘或错误定位应将目标带入视野。已有表格滚动优先用于表格本身 |

界面文字先用对象名和动词，例如「更换副本」「检测窗口」「保存设置」。删掉一句话后，如果用户仍能准确判断下一步，就删掉。保留输入格式、错误原因、费用与危险操作所需提示，放在相应控件旁。计划摘要放在共享标题区，同一页不再重复一遍。

## 状态与交付检查

- 草稿修改立即反映到预览，只有「保存设置」写入配置。切页、返回和取消保留各自已有语义。
- 运行中锁定会修改任务的控件，保持可查看的进度和停止入口。状态用文字区分等待、进行中、中断、待核对与完成。保留已有核实结果及失败原因。
- 功能接线复用现有设置、启动、事件和报告入口。独立玩法或领奖写清执行范围和资源选项，费用预览使用当前草稿，执行结果使用本次证据。
- 提交前对照默认和最小窗口，核对一级导航、二级分类、主动作、键盘焦点、长文本和滚动。用假后端检查可用、禁用、失败及保存状态，按影响范围补原生核验。视觉检查和真实游戏流程验收分别记录。[验收记录](../VALIDATION.md)

P2的实现例为「设置 → 游戏连接」。一级设置图标保持选中，书页内显示二级分类和「客户端」表单。保留游戏程序、窗口检测和连接操作，计划摘要回到共享标题区。体力计划仍使用表格，管理员授权仍显示必要说明。
