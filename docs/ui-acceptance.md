# 界面目标与验收表

更新日期：2026-10-30。目标是让熟悉HSR的玩家一眼找到需要的操作，按已有计划一次启动日常和到期周常。用户要求视觉、交互向目前AutoZZZ的还原程度看齐，并用分组、层级、间距和按钮名称承担解释。以下记录证据范围，不以测试数量、素材数量或完成百分比代替体验结论。

## 对照基线

- HSR视觉使用已有4.6参考帧、字体和静态素材；原图版本、裁切、变换和哈希见[UI来源](../assets/ui/sources.json)及[指南背景来源](../assets/ui/guide/sources.json)。背景清单明确包含重建区域，不能据此声称全屏像素与原图完全相同。
- AutoZZZ本次只读对照任务卡浏览、方向键／Enter、详情入口、开始／暂停／停止及显式保存。所读`autozzz/game_widgets.py` SHA-256为`80965ad13504c5293244d7c1276395176d9d536da4f3e19cd5aaafe0634fbb73`，`autozzz/desktop.py`为`f85f25518ff0e0af05065f48d055c118f955f697002d169eefc1d9356ef4e191`。这是当时的本地代码基线，不代表其所有运行状态已经同机比较。
- 当前桌面实现入口为[窗口与主操作](../autohsr/gui.py)、[指南与页层级](../autohsr/desktop.py)、[设置行](../autohsr/desktop_settings.py)和[绘制组件](../autohsr/game_widgets.py)。正式包、源码提交、截图与失败记录按[验证记录](../VALIDATION.md)最新条目核对。

## 后续核对顺序

1. 体力列表已完成上述原生复核；正式包交付与用户文件保留见验证记录，后续逐项保持此证据范围。
2. 对当前包逐页核对首页、生存索引、旷宇纷争、运行记录和七类设置；分别列出默认、选中、禁用、错误、结束与接续的实际差异。
3. 优先修复影响识别下一步的差异，再核对静态装饰、字体、间距与参考图的偏差；保留原始失败记录。
4. 补齐当前包长状态与原生缩放证据，再进行用户安排的体验验收。历史截图、模拟回执和参考头像均不替代当前账号或当前客户端的真实结果。

本表不授权游戏任务、资源消耗、系统定时任务或恢复旧货币战争开发局；界面证据优先使用静态参考、假后端及独立配置窗口。
