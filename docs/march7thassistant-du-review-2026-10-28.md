# 三月七差分宇宙实现的可借鉴点

日期：2026-10-28。依据固定提交的[原生差分实现](https://github.com/moesnow/March7thAssistant/blob/7cf6c6bed474539485d3b1504077ac352866829f/tasks/weekly/divergent_universe.py)和[默认配置](https://github.com/moesnow/March7thAssistant/blob/7cf6c6bed474539485d3b1504077ac352866829f/assets/config/config.example.yaml)，对照本项目[玩法说明](differential-universe.md)、[逐局验证](du-validation.md)及`du_*.py`。没有进行同机性能或成功率对照实验。

## 值得适配的部分

| 上游机制 | 本项目现状 | 适配结论及验证要求 |
| --- | --- | --- |
| `process_next_station`从配置读取站点优先级与禁用项 | 已有站点规则、信标处理与候选核验，偏好主要写在流程中 | 值得将偏好变为可保存配置，同时保留必经站点、红三角、选中态和多卡重读规则；不能把“禁用”实现为无候选时偷偷照选 |
| `get_recorded_run_count`按日／周周期读取次数 | 已有每批局数、独立与接续记录；通关后日常按账号及04:00去重 | 可新增只读统计及周期目标，从本地已核实结算推导，不能把时间戳或启动次数当通关数 |
| `process_random_door`有稳定模式，使用短脉冲移动 | 本项目已经有短步、背景位移检查及门唤醒规则 | 值得比较慢设备上的动作时长；用真实回放和有限场景验证后再改默认值。没有证据支持直接替换既有导航 |
| 事件与门检测候选分开处理 | 本项目已有ONNX候选、文字与视觉联合门禁 | 可以补布局和遮挡反例；只复用候选层，不让颜色或检测框单独授权交互 |
| 空槽存档、单局存档尝试状态 | 本项目已有空槽、递增名与默认关闭 | 补“本局已提交保存”的持久状态，重点解决中断后是否允许重发；自动命名仍须独立实机核实 |
| 不支持区域单独标记 | 本项目已有partial及具体失败证据 | 可统一为明确的“当前区域未支持”结果，让已完成节点与退出原因同时显示 |

## 不直接搬运的行为

源码中随意门路径会连续按多次F；本项目的输入契约要求一次提交后先观察反馈，因此只参考其检测和稳定移动思路。上游有根据配置重抽站点、默认候选兜底等行为，适配时必须读取当前次数、真实候选和确认状态，不能继承固定坐标兜底。

上游周期计数直接写配置；本项目继续把任务设置与运行记录分开。上游常规／周期模式入口不证明本项目常规实机已获验收，当前已验证的周期路径不因功能对齐而被替换。

## 当前结论

优先实现可配置站点偏好、按已核实结果统计周期目标和更清楚的不支持区域结果。移动性能调整必须有测量支持；本轮未修改已验收的差分输入逻辑，也没有启动新的差分对局。既有10次独立周期通关及28次分段／接续记录保持原样。
