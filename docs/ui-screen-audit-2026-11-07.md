## 修订复核

| 编号 | 私有桌面结果 |
| --- | --- |
| HSR-01 | 五个页签逐一选中时位置与宽度不变。工具胶囊以导轨色收边。 |
| HSR-02 | 小窗口保留预算与支援同行，次数快捷操作移到下一行。重复的 8 处裁切在同一脚本中归零。 |
| HSR-03 | 运行详情收进书框，长结果可选择、复制和滚动，返回恢复原控件。窗口检测归入记录对应页签。 |
| HSR-04 | 工具分类在内容视口上方，滚动内容时保持可见。任务流空态的主操作为「新建草稿」。 |
| HSR-05 | 记录页隐藏上一页的启动动作，运行中仍可暂停及停止，返回原模式可继续查看或执行原操作。 |
| HSR-06 | 支援角色、添加／编辑副本、历战优先及补刷副本进入书内表单，明确取消或应用。候选、次数及费用门禁继续按已有条件检查。 |
| HSR-07 | 保留退出保存确认，核对临时配置未被阅读、取消或导航写入。 |

修订版同样记录 104 张截图，见 runs/audit-after-final/index.json。两种窗口均无布局裁切。四个缩放比例另走页签、工具、返回焦点和表单检查。真实游戏、窗口授权、系统文件选择、任务流外部资源及通知发送另行验收。

复核补记。培养目标页的白色与禁用胶囊曾把浅灰矩形绘入圆角外侧。修订后的胶囊边缘保留透明像素，Tk 使用实际书页、表单或底栏的背景补底。书框工具与海报入口分别使用导轨颜色和海报像素。布局冒烟按三档缩放核对四角，并覆盖普通、禁用和键盘焦点。
